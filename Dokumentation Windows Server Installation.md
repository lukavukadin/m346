# Virtuelle Maschine erstellen

## 1. Learner Lab öffnen und AWS aktivieren
- Öffnen Sie das Learner Lab und starten Sie das Lab.
- Warten Sie, bis AWS aktiviert ist, und öffnen Sie es anschließend.

![Learner Lab öffnen](https://github.com/user-attachments/assets/d7d5b78b-b73d-442e-9522-29d7a1147c47 =50x)

## 2. EC2-Dienst öffnen und Instanz starten
- Öffnen Sie den Dienst **EC2** und klicken Sie auf **Launch Instance**.

![EC2-Dienst öffnen](https://github.com/user-attachments/assets/5e241e2b-6104-4705-83d4-88746ca951a4 =50x)
![Launch Instance](https://github.com/user-attachments/assets/172d63dc-7012-4548-a1b4-5ee1ab430188 =50x)

## 3. Name der Umgebung festlegen
- Geben Sie der Instanz einen Namen, z.B. „Windows Server 2019“.

![Name der Umgebung](https://github.com/user-attachments/assets/4a875a6a-0f67-4c17-b174-0a2e9d9cb8fa =50x)

## 4. Betriebssystem auswählen
- Wählen Sie das gewünschte Betriebssystem aus.

![Betriebssystem auswählen](https://github.com/user-attachments/assets/c896d85f-bbcd-4226-b209-91b6e7f14a9f =50x)

## 5. Key Pair erstellen
- Erstellen Sie ein Key Pair, indem Sie einen Namen eingeben und auf **Create Key Pair** klicken.

![Key Pair erstellen](https://github.com/user-attachments/assets/5d995a66-d374-427d-a4d9-30f18473457f =50x)
![Key Pair erstellt](https://github.com/user-attachments/assets/cf2aef3b-1ac2-47f4-a1e9-8b2afe25c26a =50x)

## 6. Instanz starten
- Gehen Sie zurück und starten Sie die Instanz.

![Instanz starten](https://github.com/user-attachments/assets/3dcdbcd9-2a19-4470-8722-9f7622edd45c =50x)

## 7. Remote Desktop-Verbindung öffnen
- Öffnen Sie die Remote Desktop-Verbindung und geben Sie die Verbindungsdaten ein.

*Platz für Bild und genaue Beschreibung hinzufügen.*

## 8. Warten, bis die VM ausgeführt ist
- Warten Sie, bis die virtuelle Maschine vollständig gestartet ist.

*Platz für Bild und genaue Beschreibung hinzufügen.*

## 9. VM ist einsatzbereit
- Die VM ist jetzt einsatzbereit und kann verwendet werden.

*Platz für Bild und genaue Beschreibung hinzufügen.*

---

**Hinweis:** Stellen Sie sicher, dass alle Schritte vollständig abgeschlossen sind und die VM korrekt konfiguriert ist, bevor Sie sie in Ihrer Umgebung verwenden.
