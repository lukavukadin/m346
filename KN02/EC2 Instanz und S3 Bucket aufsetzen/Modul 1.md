**1. Definieren Sie Cloud Computing und seine Auswirkungen:**

- Cloud Computing ist die Bereitstellung von IT-Ressourcen über das Internet. Es ermöglicht flexiblen und kosteneffizienten Zugriff auf Speicher und Software. Dadurch profitieren Unternehmen von schnelleren Innovationen und geringeren Betriebskosten.

2. Identifizieren Sie die Vorteile von Cloud Computing.

- Kosteneffizienz:
Unternehmen können viel Geld sparen, weil sie keine teure Hardware kaufen oder pflegen müssen. Sie zahlen einfach nur für das, was sie tatsächlich nutzen.

- Flexibilität:
Cloud-Dienste lassen sich schnell anpassen, sodass Unternehmen bei Bedarf ganz einfach mehr Ressourcen hinzunehmen oder reduzieren können. Das hilft, flexibel auf Veränderungen zu reagieren.
